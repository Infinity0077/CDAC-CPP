# Day 01 MCQ (Based on C++ Basics, Variables, I/O, Operators)

1. C++ is primarily:
   - a) POP
   - b) OOP
   - c) Scripting
   - d) Query language
   - **Answer: b**

2. Entry point of program:
   - a) start()
   - b) run()
   - c) main()
   - d) init()
   - **Answer: c**

3. Header required for `cin`/`cout`:
   - a) stdio.h
   - b) iostream
   - c) string.h
   - d) math.h
   - **Answer: b**

4. Which is invalid variable name?
   - a) roll_no
   - b) a1
   - c) 3x
   - d) A
   - **Answer: c**

5. Datatype generally used for decimal values:
   - a) int
   - b) char
   - c) float/double
   - d) long int
   - **Answer: c**

6. `%` operator returns:
   - a) quotient
   - b) remainder
   - c) product
   - d) power
   - **Answer: b**

7. `a++` means:
   - a) a=a-1
   - b) a=a+1
   - c) a=a*1
   - d) a=0
   - **Answer: b**

8. `==` is:
   - a) assignment
   - b) equality comparison
   - c) logical AND
   - d) increment
   - **Answer: b**

9. Logical OR operator:
   - a) &&
   - b) ||
   - c) !
   - d) ==
   - **Answer: b**

10. `endl` in C++ is used for:
   - a) declaration
   - b) loop termination
   - c) new line/output flush
   - d) input read
   - **Answer: c**
