# Day 01 MCQ Practice

1. Which header is needed for `printf()`?
   - a) stdlib.h
   - b) stdio.h
   - c) conio.h
   - d) string.h
   - **Answer: b**

2. Which is a valid variable name?
   - a) 2num
   - b) total_marks
   - c) float
   - d) my-name
   - **Answer: b**

3. `char` typically stores:
   - a) Integer
   - b) Single character
   - c) Decimal
   - d) String
   - **Answer: b**

4. Format specifier for `int` is:
   - a) `%f`
   - b) `%d`
   - c) `%c`
   - d) `%lf`
   - **Answer: b**

5. Which operator assigns value?
   - a) ==
   - b) =
   - c) !=
   - d) <=
   - **Answer: b**
