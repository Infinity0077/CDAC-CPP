# Day 01 - C Basics: Setup, Syntax, Data Types

## 1) What is C?
- C is a procedural programming language.
- It is fast, close to hardware, and widely used in systems programming.

## 2) Program Structure
A basic C program has:
- `#include` directives
- `main()` function
- statements ending with `;`

## 3) Data Types
- `int` → integers
- `float` → decimal values
- `char` → single character
- `double` → high-precision decimal

## 4) Variables and Constants
- Variable: named memory location
- Constant: fixed value (`const` or `#define`)

## 5) Input/Output
- `printf()` for output
- `scanf()` for input

## 6) Build/Run (GCC)
```bash
gcc filename.c -o app
./app
```
