# Day 02 MCQ Practice

1. `%` operator works with:
   - a) float only
   - b) int only (in basic C context)
   - c) char only
   - d) string
   - **Answer: b**

2. Logical AND operator:
   - a) &
   - b) &&
   - c) ||
   - d) !
   - **Answer: b**

3. Ternary operator symbol:
   - a) `::`
   - b) `??`
   - c) `?:`
   - d) `=>`
   - **Answer: c**

4. `a = 5; b = a++;` then b is:
   - a) 6
   - b) 5
   - c) 4
   - d) 0
   - **Answer: b**

5. Relational operators return:
   - a) float
   - b) true/false (1/0)
   - c) char
   - d) string
   - **Answer: b**
