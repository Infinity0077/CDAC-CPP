# Day 02 MCQ (If/Else, Switch, While, Do-While)

1. `if` condition typically uses:
   - a) comparison/logical expression
   - b) include directive
   - c) class object
   - d) string only
   - **Answer: a**

2. In switch, `default` runs when:
   - a) first case matches
   - b) no case matches
   - c) always
   - d) break missing
   - **Answer: b**

3. `break` in switch:
   - a) restarts switch
   - b) exits current case block
   - c) ends program
   - d) skips input
   - **Answer: b**

4. While loop checks condition:
   - a) after body
   - b) before body
   - c) never
   - d) compile time
   - **Answer: b**

5. Do-while executes body:
   - a) only if condition true first
   - b) at least once
   - c) zero times always
   - d) twice minimum
   - **Answer: b**

6. Prime check commonly uses:
   - a) modulo divisibility test
   - b) addition only
   - c) string compare
   - d) switch default
   - **Answer: a**

7. Odd/even check uses:
   - a) n/2
   - b) n%2
   - c) n*2
   - d) n++
   - **Answer: b**

8. Nested if is useful for:
   - a) multiple dependent conditions
   - b) array declaration
   - c) class construction
   - d) function return type
   - **Answer: a**

9. `toupper(ch)` helps:
   - a) char to uppercase
   - b) char to lowercase
   - c) string reverse
   - d) integer conversion
   - **Answer: a**

10. Infinite loop can happen when:
   - a) condition never changes
   - b) using break
   - c) using `%`
   - d) with switch default
   - **Answer: a**
