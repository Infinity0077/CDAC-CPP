# Day 02 - Control Statements and Loops (if-else, switch, while, do-while)

## 1. Control Statements
Used to make decisions in programs.

### Types covered
1. Simple `if`
2. `if...else`
3. Nested `if...else`
4. `if...else` block (multiple statements)
5. `switch`

## 2. if / if-else
### Simple if
Executes only when condition is true.

### if-else
Chooses one of two paths:
- true block
- false block

### Nested if-else
Used for multiple dependent conditions (e.g., largest among 3 numbers).

### if-else block style
Use braces `{}` when there are multiple statements in either branch.

## 3. switch-case
Best for menu-driven logic.

### Keywords
- `case`
- `break`
- `default`

### Behavior
- Switch checks expression value.
- Matching case executes.
- `break` prevents fall-through.
- `default` executes when no case matches.

### Example use cases
- Calculator menu
- Vowel check using `toupper()`

## 4. Loops
Loops repeat statements while condition is satisfied.

### Loop components
- Initialization
- Condition
- Increment/Decrement

### Types covered
1. `while`
2. `do...while`

## 5. while loop
- Condition checked before execution.
- Can run zero or more times.

Common examples:
- 1 to n series
- n to 1 series
- factorial
- sum of input numbers
- prime check using flag

## 6. do-while loop
- Executes body first, condition checked later.
- Runs at least one time.

## 7. Concepts practiced in class
- Positive/negative check
- Odd/even check
- Largest among numbers
- Range checking with nested conditions
- Menu-driven calculator
- Vowel/non-vowel
- Power calculation `x^y` using loop
- Maximum in fixed number of inputs
