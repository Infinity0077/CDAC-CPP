# Day 02 - Operators and Expressions

## 1) Types of Operators
- Arithmetic: `+ - * / %`
- Relational: `== != > < >= <=`
- Logical: `&& || !`
- Assignment: `= += -= *= /= %=`
- Unary: `++ --`
- Conditional: `?:`

## 2) Precedence and Associativity
- Decide evaluation order in expressions.
- Use parentheses to avoid confusion.

## 3) Type Casting
- Implicit conversion
- Explicit cast: `(float)a`

## 4) Increment/Decrement
- Pre: `++a`
- Post: `a++`
