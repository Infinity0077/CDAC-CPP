# Day 03 MCQ (For loop, nested loop, arrays)

1. `for(init; cond; inc)` executes in first iteration:
   - a) cond -> inc -> body
   - b) init -> cond -> body
   - c) body -> init -> cond
   - d) init -> body -> cond
   - **Answer: b**

2. Nested loops are commonly used for:
   - a) headers
   - b) pattern/matrix logic
   - c) constructors
   - d) string copy
   - **Answer: b**

3. Array index in C/C++ starts at:
   - a) 1
   - b) -1
   - c) 0
   - d) depends on compiler
   - **Answer: c**

4. `int a[5]` valid index range:
   - a) 1..5
   - b) 0..4
   - c) 0..5
   - d) 1..4
   - **Answer: b**

5. Array stores elements:
   - a) random memory blocks
   - b) contiguous memory
   - c) stack only
   - d) heap only
   - **Answer: b**

6. To find max in array, you typically:
   - a) compare each element with current max
   - b) use switch-case
   - c) use strcat
   - d) use class object
   - **Answer: a**

7. Average of integer total in 5 elements should consider:
   - a) division by 10
   - b) division by 5
   - c) multiplication by 5
   - d) none
   - **Answer: b**

8. In even/odd split:
   - a) `%2==0` odd
   - b) `%2!=0` even
   - c) `%2==0` even
   - d) `%2` not used
   - **Answer: c**
