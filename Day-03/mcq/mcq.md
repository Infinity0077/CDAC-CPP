# Day 03 MCQ Practice

1. `switch` expression must be:
   - a) float only
   - b) integral/char/enum compatible
   - c) string
   - d) pointer only
   - **Answer: b**

2. `break` in switch:
   - a) exits loop only
   - b) exits switch block
   - c) pauses program
   - d) restarts case
   - **Answer: b**

3. `if (a = 10)` does:
   - a) comparison
   - b) assignment then condition check
   - c) compile error always
   - d) none
   - **Answer: b**

4. Else-if ladder is used for:
   - a) loops
   - b) multiple condition branches
   - c) arrays
   - d) functions
   - **Answer: b**

5. Default in switch:
   - a) mandatory
   - b) optional fallback case
   - c) loop condition
   - d) header file
   - **Answer: b**
