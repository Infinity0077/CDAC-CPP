# Day 04 Coding Practice (Based on string functions + 2D array + function intro + struct)

## String Programs
1. Input string and print length + each index character.
2. Convert string to uppercase and lowercase.
3. Copy one string to another (`strcpy`).
4. Concatenate two strings (`strcat`).
5. Compare two strings (`strcmp`).

## 2D Array Programs
6. Input 3x2 matrix and print matrix format.
7. Input 3x2 matrix and print max value with row/column index.

## Function Programs
8. Create `add(int,int)` function and call from main.
9. Create with-return `sq(int)` and pass result to `cube(int)`.
10. Pass 1D array to function and print sum.

## Struct Programs
11. Define `book` struct and print details of 2 books.
12. Define `Employee` struct array (5) and print total + average salary.
