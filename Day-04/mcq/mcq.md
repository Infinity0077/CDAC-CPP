# Day 04 MCQ Practice

1. Which loop runs at least once?
   - a) for
   - b) while
   - c) do-while
   - d) none
   - **Answer: c**

2. `continue` does:
   - a) exits loop
   - b) skips current iteration
   - c) restarts program
   - d) ends function
   - **Answer: b**

3. Infinite loop example:
   - a) `for(i=0;i<10;i++)`
   - b) `while(1)`
   - c) `do{}while(0)`
   - d) none
   - **Answer: b**

4. Factorial of 0 is:
   - a) 0
   - b) 1
   - c) undefined
   - d) 2
   - **Answer: b**

5. Nested loop commonly used for:
   - a) file open
   - b) pattern printing
   - c) headers
   - d) casting
   - **Answer: b**
