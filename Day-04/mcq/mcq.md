# Day 04 MCQ (Strings, 2D arrays, functions, struct)

1. String in C-style ends with:
   - a) EOF
   - b) '\0'
   - c) '\n'
   - d) '#'
   - **Answer: b**

2. `strlen(str)` returns:
   - a) total memory allocated
   - b) string length
   - c) first char
   - d) reversed string
   - **Answer: b**

3. `strcpy(dest, src)` does:
   - a) compare
   - b) concatenate
   - c) copy src into dest
   - d) reverse
   - **Answer: c**

4. 2D array needs:
   - a) one index
   - b) two indices (row/col)
   - c) three indices
   - d) no loop
   - **Answer: b**

5. UDF executes:
   - a) automatically without call
   - b) via function call from main/object usage
   - c) only in constructor
   - d) only once per program
   - **Answer: b**

6. `void` function:
   - a) must return int
   - b) returns no value
   - c) cannot print
   - d) cannot take args
   - **Answer: b**

7. Struct members are accessed using:
   - a) ::
   - b) ->
   - c) . (dot) with object
   - d) #
   - **Answer: c**

8. `strcmp(a,b)==0` means:
   - a) a>b
   - b) a<b
   - c) strings equal
   - d) invalid
   - **Answer: c**
