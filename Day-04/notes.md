# Day 04 - Loops (for, while, do-while)

## 1) for Loop
Best when iteration count is known.

## 2) while Loop
Condition checked first, useful for unknown count.

## 3) do-while
Runs at least once.

## 4) Loop Control
- `break` exits loop
- `continue` skips current iteration

## 5) Nested Loops
Used in pattern and matrix-style logic.
