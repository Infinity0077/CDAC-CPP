if....else statements
	It is used to print or execute true statement if condition is satisfied other wise it provide
false statement.
( if condition is satisfied the compiler provide true statement other wise provide false statement)
Types of if...else
1. simple if
2. if...else
3. Nested if...else
4. if..else block or embedded if ...else
Note :- Only comparison operator is used when give the condition.
1. simple if
	It is used when condition is satisfied then only required ans.
syntax
	if(condition)
	true statement;

switch
		It is type of condition which used with
case
break 
default keywords
		It is used to execute menu driven program. It is provide ans on choice variable value.
case :- In one switch provide multiple case statement but at time execute only one case related
to choice variable.

break:- it is used to terminate one case through another.
default :- if choice case is not present the default provide default ans.
syntax
switch(choice_variable)
{
case 1: process statement;
break;
case 2: process statement;
break;
default:
	default answer;
}

/*
Write a program of menu driven
1.Addition
2.Subtraction
3.Multiplication
4. Division


*/
#include<iostream>
using namespace std;
main()
{

	cout<<"1.Addition\n2.Subtraction\n3.Multiplication\n4. Division";
	cout<<"Enter Choice";
	cin>>ans;
	switch(ans)  //switch(1)
	{
		case 1: 
			c=a+b;
			cout<<"\nAddition="<<c;
		break;
		case 2: 
			c=a-b;
			cout<<"\nSubtraction="<<c;
		break;
		case 3: 
			c=a*b;
			cout<<"\nMultiplication="<<c;
		break;
		case 4: 
			c=a/b;
			cout<<"\nDivision="<<c;

		default: 
			cout<<"Invalid Choice";

}

/*
Write a program scan character and print character is vowel or not
a e i o u
A E I O U


*/
#include<iostream>
using namespace std;
main()
{
	char ch;
	cout<<"Enter Character";
	cin>>ch;
	switch(toupper(ch))
	{
		case 'A': 
			cout<<"Vowel";
		break;
		case 'E': 
			cout<<"Vowel";
		break;
		
		case 'I': 
			cout<<"Vowel";
		break;
		
		case 'O': 
			cout<<"Vowel";
		break;
		
		case 'U': 
			cout<<"Vowel";
		break;
			default: cout<<"\nNot vowel";
		
	}
				
	
	
}

toupper()  :- It is used to convert single lower character into upper character.

Loop's
	It is cycle process.
	When user know what is start, what is process and what is a stop that time used the concept of loop.
****
To execute the loop user required
initialization
condition
increment/decrement
***
Loop is execute either finite way or infinite way. loop never infinite.
***
Time complexity is depend on loop.

Note:- It is repetition of statement till the condition is satisfied.
Types of Loop
1. while
2. do ....while
3. for loop
	i)simple for loop
	ii)nested for loop

1. While 
	It is a loop which execute statement one by one.
syntax
initialization;
	while(condition)
	{
	 process statement;
	increment/decrement.
	}
Execution way
1. initialization
2. condition
3. if condition satisfied then process statement/increment or decrement.

{

		{

			a++;
		}
	
		cout<<"\nSeries n.............1";		
		a=n;
		while(a>=1)   //10>=1
		{
			cout<<"\n"<<a;
			a--;
		}
	
	
}
