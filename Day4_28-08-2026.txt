String Function
1. strlen()	:- It is stand for string length. It is return user length.
Syntax
	int variable=strlen(string);
2. strupr() :- It is stand for string upper. It is used to convert lower string into upper string.
syntax
strupr(string);

3. strlwr():- It is stand for string lower. It is used to convert upper string into lower string/
syntax
strlwr(string);
4. strcpy():- It is used to copy source string into destination string.
syntax
strcpy(dest_string,source_string);
5. strcat():- It is used to concat(join) two string an append format.
syntax
strcat(string1,string2);
		//string1 is join
6. strcmp() :- It is compare two strings using ASCII  values. If string compare then it return 0.
if(strcmp(str1,str2)==0)
string compare

7. strrev() : it is stored string in reverse.
syntax
strrev(string).

Two Dimensional Array (Two D Array)
	It is used to stored the data in a row and column format. 
	It is used to stored the elements in a matrix format.
	To implement we required row index and column index.
	Required nested for loop.
	Each data is associated with row index and column index.
Example
int a[3][2],i,j;
	
	a is a name of array
	3 is a size of row
	2 is a size of column
	i :- is used to row index
	j:- is used to column index
3*2=6 numbers stored into a array
6*4 byte is occupied

/*
Write a program scan numbers and print in matrix format
*/
#include<iostream>
using namespace std;
main()
{
	int a[3][2],i,j;
	cout<<"Enter Array Data=";
	for(i=0;i<3;i++)  //row  i=0
	{
		for(j=0;j<2;j++)  //colum j=0
		{
			cout<<"\nEnter value for a["<<i<<"]["<<j<<"]=";
			cin>>a[i][j];   //a[0][0]
		}
	}
	
	cout<<"\nMATRIX";
	for(i=0;i<3;i++) 
	{
		for(j=0;j<2;j++) 
		{
			cout<<" "<<a[i][j];
		}
		cout<<"\n";
	}
	
}

/*
Write a program scan matrix 
and print maximum number with row index and column index
*/
#include<iostream>
using namespace std;
main()
{
	int a[3][2],i,j,max=0,x,y;
	cout<<"Enter Array Data=";
	for(i=0;i<3;i++)  //row  i=0
	{
		for(j=0;j<2;j++)  //colum j=0
		{
			cout<<"\nEnter value for a["<<i<<"]["<<j<<"]=";
			cin>>a[i][j];   //a[0][0]
			if(a[i][j]>max)
			{
				max=a[j][j];
				x=i;
				y=j;
			}
		}
	}
	
	cout<<"\nMATRIX";
	for(i=0;i<3;i++) 
	{
		for(j=0;j<2;j++) 
		{
			cout<<" "<<a[i][j];
		}
		cout<<"\n";
	}
	
	cout<<"\n"<<max<< "Value present at "<<x<<"row and "<<y<<" column";
}

Function:-
		Every function required a specific parameter(argument) and with the help of parameter
every function return a specific value.
Types of Function 
	1. Standard function :-
			It is ready with code and it has a fixed syntax.
			It is execute with the help of header file.
	2. User Defined Function(UDF)
		1.It is set of instruction.
		2.One time creation and multiple used with different argument is a main purpose of function.
	     ***3. Function is not execute it self. It is execute with the help of main()
		4. UDF instruction is created by user.
Note
	UDF, Structure and class is not execute itself. it is execute with the help of main()

Terms which used at the time function creation
1. with return function
		It is create with help of int, float, double, char, string, class name, struct name.
It is strictly return a value.
Syntax
	return datatype function_name(formal parameter)
	{
		variable define;
		process statement;
	        if required print statement
		return(value); 
	}

2. without return function
		It is create using void keyword.
		In this input process and output is possible.
		It is not return any value.
Syntax
	void function_name(formal parameter)
	{
		variable define;
		process statement;
	        print statement;
		
	}

3. actual argument or parameter
		It means variable, array or object which defined in a main and used inside the function
with the help of actual argument.
4. formal argument or parameter
		It is represent the actual parameter or argument value.
5. call by value :- It is used only value not used main address of variable array or object.

6. call by ref (pointer)
Syntax
return datatype function_name(argument)
{

}
main()
{
function(actual_argument);
}

datatype
	i) in build Data type
		int, long, float, double, char, string
	ii) User Defined Data type
		Which is created outside the main program but execute using main program.
			i) struct (structure) ii) class iii)Enum 

Structure
		It is an user defined data type which create using struct keyword.
		It is create outside the main()
		It is execute with the help of main() and object of structure.
		Inside the struct defined only dynamic variable. It is used for distortion purpose.
		Related to one struct used defined multiple objects.
		All objects work in different area.
***		struct variable is access in main with the help of object and dot(.) operator
***     object size is depend of struct variable.

Syntax
	struct struct_name
	{
		variable defined.
	};
	main()
	{
	  struct struct_name object1,object2;
	}
	
note :- Only struct variable is access with the help of object.
