OOP's
	Object Oriented Programming Lang.
Feature
1. Execution is bottom to top.
2.Polymorphism
3.Inheritance
4.Data Abstraction
5. Encapsulation

	OOP is a combination of class and objects.

class :-
	class is a reserved keyword.
	It is an user defined datatype which defined outside the main().
	class is not execute itself it is execute with the help of objects and main().
	It is not occupied any type of space in a memory
	It is create with the help of 
	private, public and protected member or access specifier of class
private :-
	In this defined any type of dynamic variables, array. which is member of class and access
only inside the class.
public:-
	Inside the public defined
	functions, constructor, destructor, static function, operator overload function, virtual function.
	It is access inside the class as well as outside the class with the help of object and dot(.) operator.
protected:-
	It is used only incase of inheritance to defined variable in base class which value used in 
a derived class.

Note:- In C++ class is by default private.
***
object :- It is represent the class entity.
	      It is an instance of class.
	     related to one class user defined multiple objects and all objects work in different areas.
	    object is occupied the space in a memory. Object size is depend on class variable.
*** In C++ object is handle garbage value at the time of object initialization.

Syntax
class classname
{
	private:
		member variable or data members
	public:
		defined member function ,constructor etc
	protected:
		defined variable inside the base class.
};
main()
{
classname object1,object2;
}

Very imp concept
Constructor
	It is special feature of OOP.
	It is defined in a public member of class as class name.(Give constructor name and class name should be same)
	Constructor does not required any return data type , so it is not return a particular value.	
***  Constructor is execute when object is created. Constructor execution is depend on compiler not
	a user.
	User can't stop the execution of constructor.
*** If user assign same value to all objects so user used concept of constructor.
** In a class user defined only one default constructor but multiple parameterized constructor.
Types of constructor
1. Default constructor or parameter less constructor.
2. Parameterized constructor
3. Copy constructor
4. Dynamic constructor

2.) Parameterized constructor
		In class user defined more than one parameterized constructor.
		It is execute according to their calling and sequence of parameter.
	Syntax
	classname(parameter)
	{
	variable=parameter;
	}

/*
Example of default and parameterized constructor
*/

#include<iostream>
using namespace std;
class Sample
{
	private:
		int a,b;
		float c;
	public:
		//default constructor
		Sample()
		{
			a=100;
			b=450;
			c=400.122f;
		}
		//parameterized constructor
		Sample(int x,int y)
		{
		a=x;
		b=y;
		}
		Sample(int x,int y,float z)
		{
			a=x;
			b=y;
			c=z;
		}
		void get_data()
		{
	
			cout<<"\n A="<<a<<"\nB="<<b<<"\nC="<<c;
		}
				
}; //terminate
main()
{
	Sample myobj(78,50,7.8f);
	myobj.get_data();
	Sample obj1;
	obj1.get_data();
	Sample obj(10,20); //parameter
	obj.get_data();
	
}

3. Copy  Constructor :- It is type of parameterized constructor.
				      It is used to copy the value of one object to another object variable.
Syntax
classname(classname &obj)
{
variable=obj.variable;
}

/*
Example of default and parameterized constructor
*/

#include<iostream>
using namespace std;
class Sample
{
	private:
		int a,b;
		float c;
	public:
		//default constructor
		Sample()
		{
			a=100;
			b=450;
			c=400.122f;
		}
		//copy constructor
		
		Sample(Sample &ob)  //ob is a formal object which represent the obj1 object of main()
		{
			a=ob.a;
			
		}
		
		void get_data()
		{
	
			cout<<"\n A="<<a<<"\nB="<<b<<"\nC="<<c;
		}
				
}; //terminate
main()
{

	Sample obj1;
	obj1.get_data();
	Sample myobj(obj1);  //obj1 it is an object //copy constructor
	myobj.get_data();
	
	
}
