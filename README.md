# CDAC CPP Preparation Roadmap

This repository is organized for **day-wise CDAC preparation** with focus on:

- Coding practice (C/C++)
- MCQ practice (concepts)
- Assignments per topic
- Daily notes and revision

## Folder Structure

Each day follows the same structure:

- `coding/` → hands-on coding questions
- `mcq/` → objective questions for conceptual strength
- `assignments/` → short tasks based on the day topic
- `notes.md` → key concept notes

## Weekly Plan

- **Week 1:** C fundamentals, operators, control statements, loops
- **Week 2:** Functions, arrays, strings, pointers
- **Week 3:** Structures, file handling, dynamic memory, C++ basics
- **Week 4:** OOP, STL basics, mixed revision + mock practice

## How to Use Daily

1. Read `notes.md`
2. Solve coding questions in `coding/`
3. Attempt all MCQs in `mcq/`
4. Complete tasks in `assignments/`
5. Update progress tracker

## Progress Tracker

Use `progress-tracker.md` in root to mark completion.

Stay consistent. Daily focused work will build strong foundations for CDAC.
